## Decisions made today
- One FastAPI server plus Supabase; no separate backend service.
- Supabase CLI SQL migrations, not an ORM.
- Python 3.12.
- Title changes count as updates; versions keep full text forever; originals stored by hash.
- Manual scan trigger first, scheduler later.
- HWP: own reader for licensing reasons. DOCX: body, tables, headers, footers, footnotes, inserted tracked changes.
- AI: Responses API, not the managed Agents API; Jev classifies first, OpenAI writes second; only the changes leave the server.
- A chat assistant and email sending are a later phase, read-only first.

## Problems found and fixed
- `.env.dev` was not git-ignored until I fixed `.gitignore`; it was never committed.
- The audit log was not append-only: the project's default privileges left `service_role` able to update and delete rows. Fixed by a follow-up migration; lesson: always revoke, then grant.
- Live test caught a double-decompression crash on gzip responses that mocks missed (earlier session part).
- A new test showed an HTML error page named `.pdf` was classed as harmless hash-only; it is now a failed post.
- My edit tool turned `​`-style escapes into invisible characters in two files; rewritten with plain code points.
- Early in the project I overwrote `pyproject.toml` and `.python-version` without reading them first; the old contents are unknown.
